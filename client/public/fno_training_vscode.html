Fourier Neural Operator (FNO) - 1D Burgers (PDEBench)

Demo-Notebook für die Lehre. Es zeigt den vollständigen Ablauf eines FNO-Trainings: Daten - Modell - Training - Evaluation.

Der Datensatz stammt aus PDEBench (DARUS-2987, 1D Burgers). Das Training wurde einmal offline auf GPU gerechnet; in diesem Notebook werden nur die gespeicherten Outputs eingeblendet - kein Warten.

3. FNO-Modell

Der Fourier Neural Operator (Li et al. 2021) besteht aus einer Folge von Spektral-Layern. Pro Layer:

  • FFT der Eingabe entlang der räumlichen Dimension
  • Multiplikation mit gelernten komplexen Gewichten - nur die ersten MODES Fourier-Moden
  • Inverse FFT zurück in den Ortsraum
  • Residual-Verbindung über eine 1x1-Faltung
[ ]
1class SpectralConv1d(nn.Module):
2 def __init__(self, in_ch, out_ch, modes):
3 super().__init__()
4 self.in_ch, self.out_ch, self.modes = in_ch, out_ch, modes
5 scale = 1 / (in_ch * out_ch)
6 self.weights = nn.Parameter(
7 scale * torch.rand(in_ch, out_ch, modes, dtype=torch.cfloat))
8
9 def forward(self, x):
10 B = x.shape[0]
11 x_ft = torch.fft.rfft(x) # (B, C, N//2+1)
12 out_ft = torch.zeros(B, self.out_ch, x.size(-1)//2+1,
13 dtype=torch.cfloat, device=x.device)
14 out_ft[:, :, :self.modes] = torch.einsum(
15 'bix,iox->box', x_ft[:, :, :self.modes], self.weights)
16 return torch.fft.irfft(out_ft, n=x.size(-1))
keine Ausgabe — reine Klassendefinition.
[ ]
1class FNO1d(nn.Module):
2 def __init__(self, modes=MODES, width=WIDTH, n_layers=N_LAYERS):
3 super().__init__()
4 self.fc_in = nn.Linear(2, width) # [u(x), x] -> width
5 self.specs = nn.ModuleList([SpectralConv1d(width, width, modes)
6 for _ in range(n_layers)])
7 self.ws = nn.ModuleList([nn.Conv1d(width, width, 1)
8 for _ in range(n_layers)])
9 self.fc_out = nn.Sequential(nn.Linear(width, 128), nn.GELU(),
10 nn.Linear(128, 1))
11
12 def forward(self, x): # x: (B, N, 1)
13 grid = torch.linspace(0, 1, x.size(1), device=x.device)
14 grid = grid.view(1, -1, 1).expand(x.size(0), -1, 1)
15 x = torch.cat([x, grid], dim=-1) # (B, N, 2)
16 x = self.fc_in(x).permute(0, 2, 1) # (B, width, N)
17 for spec, w in zip(self.specs, self.ws):
18 x = F.gelu(spec(x) + w(x))
19 x = x.permute(0, 2, 1)
20 return self.fc_out(x).squeeze(-1)
21

23n_params = sum(p.numel() for p in model.parameters())
24print(f'FNO1d: {n_params:,} Parameter')

4. Training

Adam-Optimizer mit Cosine-Annealing-LR-Scheduler. Loss: relative L2-Norm (typisch für PDE-Solver, robuster als MSE bei unterschiedlichen Lösungsamplituden).

[ ]
1optimizer = torch.optim.Adam(model.parameters(), lr=LR, weight_decay=WEIGHT_DECAY)
2scheduler = torch.optim.lr_scheduler.CosineAnnealingLR(optimizer, T_max=EPOCHS)
3
rel-L2MSEH1
4def rel_l2_loss(pred, target):
5 num = torch.norm(pred - target, p=2, dim=-1)
6 denom = torch.norm(target, p=2, dim=-1)
7 return (num / denom).mean()
4def mse_loss(pred, target):
5 return ((pred - target) ** 2).mean()
4def h1_loss(pred, target, alpha=0.1):
5 l2 = torch.norm(pred - target, p=2, dim=-1).mean()
6 dp = pred[..., 1:] - pred[..., :-1]
7 dt = target[..., 1:] - target[..., :-1]
8 return l2 + alpha * torch.norm(dp - dt, p=2, dim=-1).mean()
keine Ausgabe — Optimizer, Scheduler und Loss-Funktion werden nur definiert.

9. Zusammenfassung

  • FNO mit ~0.55 M Parametern lernt 1D-Burgers (Nu=0.01) auf rel-L2 ~ 0.42 %.
  • Training auf 900 Samples, 500 Epochen, ca. 6.4 min auf einer RTX 4090.
  • Auflösungsinvariant: trainiert auf 1024 Gitterpunkten, generalisiert auf 2048 ohne Retraining.
  • Modell gespeichert unter models/fno_burgers_best.pt (1.2 MB).
